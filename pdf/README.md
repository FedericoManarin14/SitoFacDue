# Required PDF Files — FAC DUE s.r.l.

Place all PDF catalogue files in this `pdf/` directory.
These are linked from the "Download Cataloghi" section on `abrasivi.html`.

| Filename | Catalogue |
|---|---|
| `swediam.pdf` | SWEDIAM product catalogue |
| `riellight.pdf` | Riel Light product catalogue |
| `sifa.pdf` | SIFA product catalogue |
| `sorma.pdf` | SORMA product catalogue |

## Notes
- Each PDF opens in a new browser tab when the corresponding link is clicked
- Files are not tracked by git if a `.gitignore` excludes `pdf/*.pdf` — add them manually or adjust `.gitignore` as needed
